# Прогноз акций Мосбиржи по новостям

Учебный дашборд: дневные цены бумаг с Мосбиржи, новости каналов РИА Новости и Mash, прогноз доходности **следующего торгового дня**. Это не инвестиционная рекомендация.

## Что внутри

Пять сегментов, бумага с коротким рядом после переезда на биржу в сезонный график не входит:

- Сельское хозяйство: GCHE, AQUA, PHOR, RAGR (с 17.02.2025, без сезонности)
- Топливный: GAZP, LKOH, ROSN
- Логистика: FESH, NMTP, FLOT
- Банки: SBER, VTBR, T (история тикера T с 28.11.2024, без сезонности)
- Бигтех: VKCO, POSI, YDEX (с 24.07.2024, без сезонности)

Цены — публичный ISS, режим TQBR, окно 2023-10-12 … 2026-10-12. Новости — публичные каналы `@rian_ru` и `@mash`. В модель попадают посты, где есть название компании, слово сегмента или макрослово (ставка, ЦБ, санкции, курс рубля, инфляция).

Прогноз — LightGBM. Признаки: тональность (`seara/rubert-tiny2-russian-sentiment`), число новостей, доходности за 1, 5 и 20 дней, объём, месяц и день недели. Обучение на первых двух годах, проверка на последнем. Рядом с ошибкой модели показан наивный прогноз «доходность 0» и правило «знак как вчера».

## Запуск

```text
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

В `.env` вставьте `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` с https://my.telegram.org . Первый сбор новостей спросит номер телефона и код входа. Файл сессии лежит в `data/` и в git не попадает.

```text
python -m src.collect_prices
python -m src.collect_news
python -m src.train
streamlit run src/app.py
```

Повторный `collect_news` догружает новые сообщения. Если сбор оборвался, следующий запуск продолжает историю с места остановки. На вкладке «Новая новость» можно вставить текст или взять последние сохранённые посты канала. Если текст не про эти бумаги, прогноз по всему списку не строится.
